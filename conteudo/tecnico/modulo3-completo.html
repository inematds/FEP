1. Decomposição de Tarefas

Quebre problemas complexos

Tarefas complexas geram melhores resultados quando divididas em subtarefas menores e focadas.

❌ Tarefa única complexa:

"Analise este documento, extraia dados, crie resumo e gere recomendações"

✓ Tarefas decompostas:

1. "Extraia os dados principais deste documento"

2. "Analise os dados extraídos e identifique padrões"

3. "Crie um resumo executivo da análise"

4. "Gere 5 recomendações baseadas no resumo"

✓ Benefícios

Maior precisão, debug fácil, reuso de componentes

🎯 Quando usar

Tarefas com múltiplas etapas ou tipos de processamento

⛓️

2. Prompt Chaining

Conecte prompts em sequência

O output de um prompt alimenta o input do próximo. Crie pipelines de processamento.

Prompt 1

Extração

Prompt 2

Prompt 3

Síntese

💡 Dica

Mantenha cada prompt focado em uma única responsabilidade. Facilita manutenção e debug.

📊

3. Prompts Multi-Etapas

Múltiplas fases em um prompt

Guie o modelo através de fases sequenciais dentro de um único prompt.

# Prompt Multi-Etapas

Execute as seguintes etapas em ordem:

**ETAPA 1 - ANÁLISE:**

Identifique os 3 principais problemas no texto.

**ETAPA 2 - PRIORIZAÇÃO:**

Ordene por impacto (alto/médio/baixo).

**ETAPA 3 - SOLUÇÕES:**

Proponha uma solução para cada problema.

🎯

4. Planejar → Executar → Revisar

Framework de 3 fases

Separe planejamento de execução para resultados mais consistentes.

1️⃣ PLANEJAR

"Crie um plano detalhado para resolver [X]. Não execute ainda."

2️⃣ EXECUTAR

"Execute o plano acima passo a passo."

3️⃣ REVISAR

"Revise a execução e identifique melhorias."

🔄

5. Refinamento Iterativo

Melhore através de ciclos

Use o output como base para refinamento em ciclos subsequentes.

# Ciclo de Refinamento

Prompt 1: "Escreva um rascunho sobre [X]"

Prompt 2: "Melhore este texto focando em [CRITÉRIO]"

Prompt 3: "Refine novamente considerando [FEEDBACK]"

🧠

6. Controle de Contexto em Cadeias

Gerencie informações entre prompts

Decida o que passar adiante e o que descartar para otimizar tokens e foco.

1.

Summarize before passing

Resuma outputs longos antes de passar para próximo prompt.

2.

Extract key entities

Extraia apenas entidades relevantes para próxima etapa.

3.

State management

Mantenha "estado" estruturado (JSON) entre chamadas.
