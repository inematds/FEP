1. Markdown e Formatação Rica

Títulos, bullets, código, destaques

Instrua a IA a formatar com Markdown para respostas organizadas e legíveis.

"Formate sua resposta usando Markdown:

- Use ## para títulos de seção

- Use - para listas

- Use **bold** para destacar

- Use ```code``` para código"

# H1

**bold**

- lista

`code`

3. Templates Reutilizáveis

Crie uma vez, use infinitamente

Peça à IA criar templates com placeholders [CAMPO] para reutilização.

"Crie um template de email de [TIPO] com:

- Placeholders em [COLCHETES]

- Instruções para preencher cada campo

- 2-3 variações de tom"

💡 Exemplo de Placeholder

"Olá [NOME], sobre [ASSUNTO], gostaria de [OBJETIVO]..."
