1. LLM Basics e Funcionamento

A tecnologia por trás da IA generativa

Um Large Language Model (LLM) é um modelo de IA treinado em bilhões de palavras de texto. Através desse treinamento massivo, ele aprende padrões de linguagem, conhecimento factual e capacidades de raciocínio.

⚙️ O Processo de Geração

📚

1. Treino

Bilhões de textos

🔍

2. Padrões

Identifica regras

💬

3. Prompt

Você pergunta

✨

4. Geração

Token por token

📊 Características Importantes

  • • Não tem consciência - É uma ferramenta matemática sofisticada
  • • Baseado em probabilidade - Escolhe palavras mais prováveis
  • • Sem memória persistente - Cada conversa é isolada
  • • Data de corte - Não sabe eventos após o treinamento

2. Tokens e Janela de Contexto

As unidades básicas de processamento

Tokens são como o LLM "lê" texto. Uma palavra pode ser 1 token ou vários tokens. ~4 caracteres = 1 token em português.

📝 Exemplos

"Olá"

= 1 token

"Brasília"

= 2 tokens (Bras + ília)

📦 Context Window por Modelo

Claude 3.5 Sonnet 200K tokens
GPT-4 Turbo 128K tokens
Gemini 1.5 Pro 1M tokens

⚠️ O que conta no context window:

Seu prompt + histórico da conversa + resposta do modelo + exemplos fornecidos
