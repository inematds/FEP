1. Descomposición de tareas

Divide los problemas complejos

Las tareas complejas generan mejores resultados cuando se dividen en subtareas más pequeñas y específicas.

❌ Tarea única compleja:

"Analiza este documento, extrae datos, crea un resumen y genera recomendaciones"

✓ Tareas descompuestas:

1. "Extrae los datos principales de este documento"

2. "Analiza los datos extraídos e identifica patrones"

3. "Crea un resumen ejecutivo del análisis"

4. "Genera 5 recomendaciones basadas en el resumen"

✓ Beneficios

Mayor precisión, depuración fácil, reutilización de componentes

🎯 Cuándo usarlo

Tareas con múltiples etapas o tipos de procesamiento

⛓️

2. Prompt Chaining

Conecta prompts en secuencia

El output de un prompt alimenta el input del siguiente. Crea pipelines de procesamiento.

💡 Consejo

Mantén cada prompt enfocado en una sola responsabilidad. Facilita el mantenimiento y la depuración.

📊

3. Prompts de varias etapas

Múltiples fases en un prompt

Guía al modelo a través de fases secuenciales dentro de un único prompt.

# Prompt de varias etapas

Ejecuta los siguientes pasos en orden:

**ETAPA 1 - ANÁLISIS:**

Identifica los 3 problemas principales del texto.

**ETAPA 2 - PRIORIZACIÓN:**

Ordena por impacto (alto/medio/bajo).

**ETAPA 3 - SOLUCIONES:**

Propón una solución para cada problema.

🎯

4. Planificar → Ejecutar → Revisar

Framework de 3 fases

Separa la planificación de la ejecución para obtener resultados más consistentes.

1️⃣ PLANIFICAR

"Crea un plan detallado para resolver [X]. Todavía no lo ejecutes."

2️⃣ EJECUTAR

"Ejecuta el plan anterior paso a paso."

3️⃣ REVISAR

"Revisa la ejecución e identifica mejoras."

🔄

5. Refinamiento iterativo

Mejora mediante ciclos

Usa el resultado como base para refinarlo en ciclos posteriores.

# Ciclo de refinamiento

Prompt 1: "Escribe un borrador sobre [X]"

Prompt 2: "Mejora este texto centrándote en [CRITERIO]"

Prompt 3: "Refina nuevamente teniendo en cuenta [FEEDBACK]"

🧠

6. Control del contexto en cadenas

Gestiona información entre prompts

Decide qué transmitir y qué descartar para optimizar los tokens y el enfoque.

1.

Summarize before passing

Resume resultados largos antes de pasar al siguiente prompt.

2.

Extract key entities

Extrae solo las entidades relevantes para la siguiente etapa.

3.

Gestión del estado

Mantén un «estado» estructurado (JSON) entre llamadas.

💼
